# 6seasonsorganic Backend

Node.js/Express backend for the 6seasonsorganic ecommerce website.

## Features
- Connects to MongoDB Atlas
- API endpoints for products, users, cart, orders (to be added)

## Getting Started

1. Install dependencies:
   npm install

2. Start the server:
   node index.js

3. The server will run on http://localhost:5000 by default.

## Environment Variables
- `MONGO_URI` (optional): MongoDB Atlas connection string. If not set, the default URI in `index.js` will be used.

---

**Note:**
- Add your API routes in the `backend` folder as needed.
