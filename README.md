# 6seasonsorganic Ecommerce Project

This project contains a full-stack ecommerce website for the 6seasonsorganic brand.

## Structure
- `frontend/` - React app (with Firebase Authentication)
- `backend/` - Node.js/Express API (with MongoDB Atlas)

## Features
- User authentication (sign in/sign up) via Firebase
- Dynamic product catalog, featured/most selling products
- Cart, checkout, billing address, and order management
- Contact us page
- Components: Navbar, Footer, Logo, etc.
